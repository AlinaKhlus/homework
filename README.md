# Проект "Home Work"

## Описание:
Данный проект служит для выполнения домашних заданий и создания виджета банковского приложения которое маскирует номер 
карты или счета, изменение даты из формата `2024-03-11T02:26:18.671407` в `дд.мм.гггг`,а так же проверяет транзакции 
по типу валюты, типу платежа и генерирует номер карты

## Установка:
1. Клонируйте репозитори: \
```git clone git@github.com:AlinaKhlus/homework.git```
2. Установите зависимости:\
`poetry install`\
`poetry add --group lint flake8`\
`poetry add --group lint mypy`\
`poetry add --group lint black`\
`poetry add --group lint isort`
## Использование:
1. Функция `get_mask_card_number` скрывает часть номера карты
2. Функция `get_mask_account` скрывает часть номера счета
3. Функция `mask_account_card` использует функции из п.1 и п.2 и маскирует не только номер карты или счета, но и добавляет тип карты или счета
4. Функция `get_date` принимает дату в формате `2024-03-11T02:26:18.671407` и возвращает `дд.мм.гггг`
5. Функция `filter_by_state` сортирует операции по статусу `EXECUTED`
6. Функция `sort_by_date` сортирует операции по дате (по убыванию)
7. Функция `filter_by_currency` поочередно выдает транзакции, где валюта операции соответствует заданной
8. Функция `transaction_descriptions` возвращает описание каждой операции по очереди
9. Функция `card_number_generator` генерирует номер карты в заданном диапазоне
10. Реализована поддержка чтения финансовых операций из файлов форматов CSV и Excel (XLSX) через библиотеку pandas. 
Данные возвращаются в виде списка словарей, аналогично JSON-файлу.
### Декораторы:
В проекте реализован декоратор `log`, который автоматически записывает:
начало и успешное завершение функции `ok`
ошибки с типом исключения, а также входные параметры `args, kwargs`.
