# Проект "Home Work"

## Описание:
Данный проект служит для выполнения домашних заданий и создания виджета банковского приложения которое маскирует номер карты или счета

## Установка:
1. Клонируйте репозитори: \
```git clone git@github.com:AlinaKhlus/homework.git```
2. Установите зависимости:\
`poetry install`\
`poetry add --group lint flake8`\
`poetry add --group lint mypy`\
`poetry add --group lint black`\
`poetry add --group lint isort`
## Использование:
1. Функция `get_mask_card_number` скрывает часть номера карты
2. Функция `get_mask_account` скрывает часть номера счета
3. Функция `mask_account_card` использует функции из п.1 и п.2 и маскирует не только номер карты или счета, но и добавляет тип карты или счета
4. Функция `get_date` принимает дату в формате `2024-03-11T02:26:18.671407` и возвращает `дд.мм.гггг`
5. Функция `filter_by_state` сортирует операции по статусу `EXECUTED`
6. Функция `sort_by_date` сортирует операции по дате (по убыванию)
